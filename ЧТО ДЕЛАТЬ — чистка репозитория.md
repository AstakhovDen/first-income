# Чистка репозитория на GitHub (одноразовая операция)

## Зачем

Раньше на GitHub уезжали и скрипты - а внутри `ЗАШИФРОВАТЬ.py` лежит пароль страницы
открытым текстом. Репозиторий публичный, значит пароль мог увидеть кто угодно.

Теперь скрипты остаются только на этом компьютере, а на GitHub уходит
только зашифрованная страница и иконки. Пароль и ссылка на сайт НЕ меняются -
партнёрам ничего переделывать не нужно.

---

## Три шага

### 1. Удалить старый репозиторий

Пароль остался в старых коммитах, поэтому историю надо снести целиком.

1. Открой https://github.com/AstakhovDen/first-income/settings
2. Пролистай в самый низ, до красной зоны **Danger Zone**
3. **Delete this repository** -> подтвердить (GitHub попросит вписать `AstakhovDen/first-income`)

### 2. Создать заново с тем же именем

1. Открой https://github.com/new
2. Repository name: **first-income**
3. Выбрать **Public** (обязательно: на бесплатном плане Pages работает только из публичного)
4. Галочки «Add a README», «.gitignore», «license» - НЕ ставить, репозиторий должен быть пустой
5. **Create repository**

### 3. Запустить пересборку

Двойной клик по **`ПЕРЕСОБРАТЬ_РЕПО.py`** в этой папке.

Скрипт соберёт свежую страницу, создаст чистую историю и отправит на GitHub.
Перед отправкой он сам проверяет, что ни один `.py` файл не попал в список - если попал, останавливается.

---

## После этого

Включить страницу заново (репозиторий новый, настройка сбросилась):

1. https://github.com/AstakhovDen/first-income/settings/pages
2. **Source**: Deploy from a branch
3. **Branch**: `main`, папка `/ (root)` -> **Save**

Через минуту-две проверить: https://astakhovden.github.io/first-income/
Пароль прежний. Внизу страницы - номер версии.

---

## Дальше всё как раньше

Обновление страницы - двойной клик по **`ОБНОВИТЬ_САЙТ.py`**, как обычно.
`ПЕРЕСОБРАТЬ_РЕПО.py` больше не нужен, он одноразовый.

⚠️ Скрипты `ЗАШИФРОВАТЬ.py` и `ОБНОВИТЬ_САЙТ.py` теперь живут ТОЛЬКО на этом компьютере.
Их резервная копия - в базе Tycho Sector. На GitHub они больше не попадают никогда.
